## L01 · 仓库布局与构建

### 结论

- 产品主体在 `codex-rs/`：Cargo workspace，**166** members；`cargo metadata --no-deps` 包数 **171**。
- 分层：`codex-protocol`（`Op`/`EventMsg`）→ `codex-core` → `codex-api` → `codex-tools` → `codex-cli` / `tui` / `exec` / `app-server`。
- UI **不**直接调 `run_turn`；只提交 `Op`、消费 `EventMsg`。
- 工具链钉在 `1.95.0`。

### 关键符号

| 符号 | 位置 |

| `Op` | `protocol.rs:696`；用户文本 = `Op::TurnInput`（749） |
